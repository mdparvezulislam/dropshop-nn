# ORDER-ENGINE-001 — Enterprise Order Operations Center

## Status: Approved ✅

## Scope

Build a production-ready Enterprise Order Operations Center for Bangladesh-focused retail, reseller, and wholesale businesses. Extends existing ORDER-001 engine with complete operations workspace, invoice engine, return/warranty/exchange modules, courier integration layer, and automation.

## Architecture

Feature-first DDD under `src/features/order/`. Extends existing 17-state machine with return, warranty, exchange sub-state machines. No rebuild — enhancement only.

### New Domain Entities

- `ReturnEntity` — id, orderId, orderNumber, items[], reason, status (requested→approved→received→inspecting→approved_for_refund→rejected→refunded→completed), inspectionNotes, refundAmount, createdAt/updatedAt
- `WarrantyEntity` — id, orderId, orderNumber, productId, issue, status (requested→approved→in_repair→repaired→replaced→completed→rejected), resolution, createdAt/updatedAt
- `ExchangeEntity` — id, orderId, orderNumber, items[], reason, status (requested→approved→pickup_scheduled→picked_up→replacement_shipped→delivered→completed→rejected), createdAt/updatedAt

### New Services

- `ReturnService` — create, transition, inspect, approve, reject, refund
- `WarrantyService` — create, transition, repair, replace, complete, reject
- `ExchangeService` — create, transition, schedule pickup, ship replacement, complete
- `InvoiceService` (enhanced) — generate with reseller branding (shop name, logo, phone, address, custom footer), packing slip, money receipt
- `PrintService` — thermal/A4 invoice, packing slip, courier label, multi-order batch
- `BulkService` — confirm, print, book courier, mark packed, export, cancel
- `NoteService` — add (internal/customer/courier), list
- `ActivityLogService` — record, list

### Integration Points

- **Pricing Hub**: Query `searchProductPricingAction` for pricing. Never calculate locally.
- **Inventory**: Reserve at confirmed, deduct at packed, restore on cancel/return.
- **Wallet**: Profit release on completed, reversal on refunded via `FinanceService`.
- **Notification**: Publish events for all lifecycle transitions.
- **Courier**: Adapter layer for Steadfast, Pathao, RedX, eCourier, Paperfly.

### Bangla UX

70% English / 30% Clean Bangla. Labels, statuses, notifications, empty states use bilingual text. Technical terms (SKU, COD, API) remain English.

## Database Changes

- New collections: `returns`, `warranties`, `exchanges`, `order_notes`, `order_activity_logs`
- Enhanced `invoices` collection: reseller branding fields

## State Machines

Return: requested → approved → received → inspecting → approved_for_refund → rejected → refunded → completed
Warranty: requested → approved → in_repair → repaired → replaced → completed → rejected  
Exchange: requested → approved → pickup_scheduled → picked_up → replacement_shipped → delivered → completed → rejected
