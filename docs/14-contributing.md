# 14 - Contributing Guidelines

## Commit Message Format

- We follow conventional commits: `<type>(<scope>): <subject>`
- Types:
  - `feat`: A new feature.
  - `fix`: A bug fix.
  - `docs`: Documentation updates.
  - `style`: Formatting edits (no code changes).
  - `refactor`: Restructuring code.
  - `chore`: Modifying build tasks or config files.

## Pull Request Flow

- Create feature branch (`feature/my-feature`).
- Write tests and ensure all pre-commit checks pass.
- Open PR targeting the `dev` branch.
- Request reviews from at least one reviewer.
