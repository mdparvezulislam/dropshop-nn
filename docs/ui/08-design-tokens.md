# 08 — Design Tokens

Defined in `src/app/globals.css` as HSL channels + `@theme` Tailwind bridges.

## Surfaces

`--background`, `--foreground`, `--card`, `--popover`, `--muted`, `--accent`

## Brand

`--primary` — electric indigo  
`--sidebar`, `--sidebar-accent`, `--sidebar-active`

## Semantic

`--success`, `--warning`, `--info`, `--destructive`

## Radius

`--radius-sm|md|lg|xl` (default lg ≈ 0.75rem)

## Shadows

`--shadow-xs|sm|md|lg|glow`

## Layout

`--sidebar-width: 16.5rem`  
`--sidebar-collapsed: 4.25rem`  
`--topbar-height: 3.5rem`  
`--content-max: 90rem`

## Dark mode

Default workspace is **dark** (`.dark` on `<html>`). Light tokens exist for future toggle.
