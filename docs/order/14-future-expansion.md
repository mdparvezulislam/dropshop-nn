# 14 - Order Future Expansion

## Roadmap

1. **Multi-Warehouse Routing**:
   - Route order line items dynamically to different warehouses based on safety stock levels.
2. **Order Splitting**:
   - Split single customer orders into sub-orders dynamically by supplier references.
3. **Automated Return Audits**:
   - Automatically reconcile returned items with stock levels and trigger wallet partial refund payouts.
