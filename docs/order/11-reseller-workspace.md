# 11 - Reseller Order Workspace

## Display Panels

1. **Filtered Orders Table**: Displays only orders placed by the authenticated reseller.
2. **Profit Preview**: Shows reseller share payout earnings calculated as: `SellingPrice - WholesalePrice/CostBasis`.
3. **Logistics & Tracking**: Access tracking links and courier names immediately.
4. **Order Timeline**: Visual step timeline displaying status progression audits.
