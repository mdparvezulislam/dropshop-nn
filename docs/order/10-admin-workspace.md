# 10 - Admin Order Workspace

## Dashboard Panel

1. **Kanban Status Board**: Tracks operational order groups by status columns. Supports triggers for advancing order states.
2. **Order Filters**: Quick filter tabs for active, pending, ready for dispatch, out for delivery, and completed/cancelled items.
3. **Advanced Search**: Search orders by customer name, phone number, or order identifier code.
4. **Fulfillment Controls**: Direct forms for courier configuration mapping and note logging audits.
