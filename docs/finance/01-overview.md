# 01 - Finance Overview

## Purpose
The Finance, Wallet & Ledger Engine (FINANCE-001) is the single source of truth for platform cash flow, wallets, settlements, and withdrawals.

## Core Pillars
- **Ledger-First Architecture**: Wallet balances are computed as derived parameters from transactions.
- **Profit Release waiting hold**: Automates hold releases for reseller order profits.
- **Logistics Invoice Tracking**: Automatically creates invoicing objects on completed sales.
