# 17 - Finance Engine Implementation

## Implementation structure
- `src/features/finance/domain/` - domain entities.
- `src/features/finance/repositories/` - mongoose schemas and repository structures.
- `src/features/finance/services/` - core services and background jobs.
- `src/features/finance/actions/` - server actions checking RBAC permissions.
- `src/features/finance/types/` - validation rules.
