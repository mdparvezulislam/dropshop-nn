# 📸 Hero Banner Image Specifications

Place your real hero banner images in this folder (`/public/images/hero/`).

## Specifications:
- **Recommended File Names**:
  - `hero-banner-1.webp` (Slide 1: Electronics / Gadgets)
  - `hero-banner-2.webp` (Slide 2: Reseller Hub)
  - `hero-banner-3.webp` (Slide 3: Wholesale Deals)
- **Dimensions**: `1200 x 800 px` (Width x Height)
- **Aspect Ratio**: `3:2` or `4:3`
- **File Formats**: `.webp` (recommended for fast loading), `.jpg`, or `.png`
- **Max File Size**: `< 250 KB` per image (optimized for performance)

*Note: If no image file is found in this directory, the storefront automatically renders a polished, brand-aligned vector illustration as fallback.*
