# 🏷️ Category Thumbnail Image Assets

Place category thumbnails in this folder (`/public/images/categories/`).

## Recommended Naming Convention:
- `electronics-gadgets.webp`
- `home-kitchen.webp`
- `fashion-lifestyle.webp`
- `mobile-accessories.webp`
- `beauty-personal-care.webp`
- `baby-kids.webp`
- `sports-outdoors.webp`
- `smartwatches-fitness.webp`

## Specifications:
- **Dimensions**: `400 x 400 px` (Square 1:1)
- **Format**: `.webp` or `.png`
- **Max File Size**: `< 50 KB` per image
